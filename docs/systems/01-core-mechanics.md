## 1. 게임 개요와 디자인 필러

**컨셉 한 줄 요약**: 봉인에서 깨어난 마지막 신수(神獸) 구미호 '백연'이, 허공에서 소환하는 요마 참살의 검 '사인참사검(四寅斬邪劍)'과 1600년간 갈고닦은 도술로 조선 팔도에 창궐한 사귀(邪鬼)를 베어나가는 액션 싱글플레이어.

### 디자인 필러 (모든 시스템 판단의 상위 기준)
| # | 필러 | 의미 | 금지사항 |
|---|------|------|----------|
| P1 | **검은 부르는 것이다** | 검을 "쥐고 있는 물건"이 아니라 "공간에 배치하고 부르는 존재"로 다룬다. 소환 위치·타이밍·개수가 곧 전투의 언어 | 검을 단순 근접무기로 퇴화시키는 설계 |
| P2 | **천년 묵은 여우의 교활함** | 정면 승부보다 환술·매혹·기만으로 판을 짜는 전투. 플레이어가 "속이는 쾌감"을 느껴야 함 | 힘 대 힘의 단순 스탯 승부 |
| P3 | **신수의 격(格)** | 성장은 "새 능력 획득"이 아니라 "봉인으로 잃은 신격(神格)의 회복". 서사와 성장의 일치 | **꼬리를 스킬 슬롯/게이지/성장 단계로 쓰는 모든 설계 (절대 금지)** |
| P4 | **읽고, 어긋내고, 벤다** | 적의 패턴을 읽고(읽기), 환술·이동으로 어긋내고(기만), 검으로 마무리(처형)하는 3박자 리듬 | 버튼 연타만으로 해결되는 전투 |

### 꼬리에 대한 처리 원칙 (명문화)
- 꼬리 9개는 **연출·서사·상태 표현 전용**이다. 예: 도력이 충만하면 꼬리 끝에 여우불이 맺히고, 신기해방 시 아홉 꼬리가 펼쳐지는 **비주얼 피드백**으로만 사용.
- 꼬리 개수는 게임 시작부터 끝까지 항상 9개. 해금·성장·게이지·슬롯·스킬트리 어디에도 꼬리를 매핑하지 않는다.
- 구미호다움의 게임플레이 표현: **호화(여우불) / 환술(幻術) / 매혹(魅惑) / 변화(變化, 변신술)** 4요소로 구현한다.

## 2. 코어 게임플레이 루프

### 2.1 마이크로 루프 (초 단위: 전투 1교전)
```
[읽기] 적 패턴·살기(殺氣) 표식 관찰
   ↓
[기만] 환영 분신·매혹·연막으로 적의 행동을 어긋냄 (도력 소비)
   ↓
[참격] 검술 콤보 + 소환 발도로 딜 누적 (기력 소비, 도력 회수)
   ↓
[처형] '사기 노출' 상태의 적을 참사(斬邪) 처형 → 정기 대량 획득
   ↓ (자원 순환: 검이 벤 사기 → 도력 충전 → 다음 기만의 밑천)
```
- **핵심 순환 룰**: 도술은 도력을 쓰고, 검은 도력을 번다. 검격 적중 시 도력이 회복되므로 "도술만 쓰는 원거리 캐릭"도 "검만 쓰는 근접 캐릭"도 성립하지 않게 강제한다. (상세 수치: 04 밸런스 문서)

### 2.2 미드 루프 (분 단위: 탐험 1구간)
```
탐험(여우 형태 이동/추적) → 조우(전투/환술 퍼즐) → 보상(정기·신물·기연)
→ 사당(社堂) 정비(성장/제작/저장) → 다음 구간
```
- 필드는 반개방형 구역 연결(메트로바니아 라이트). 여우 형태의 **영맥(靈脈) 감지**로 숨은 길·매장 신물을 추적.
- 사당은 세이브 포인트 + 성장 허브. 사당 간 축지(縮地) 이동 지원.

### 2.3 매크로 루프 (시간 단위: 챕터)
```
장(章) 시작 → 봉인지(封印地) 3~4곳 탐파 → 대사귀(보스) 참살
→ 신격 1단 회복(권능 각인) → 백연의 기억 회상(서사) → 다음 장
```
- 총 6장 + 종장. 각 장의 보스는 백연이 봉인되기 전 인연이 있던 존재들로, 성장(신격 회복)과 서사가 1:1로 맞물린다.

## 3. 자원 시스템 (핵심 룰)

### 3.1 3대 자원 정의
| 자원 | 한자 | 역할 | 회복 수단 | 소진 시 |
|------|------|------|-----------|---------|
| **체력(體力)** | 命 | 생존 자원. 0이 되면 사망 | 영약(휴대 회복, 사당에서 충전), 사당 휴식, 일부 권능 | 사망 → 사당 부활, 미회수 정기 현장 잔류 |
| **기력(氣力)** | 氣 | 육체 행동 자원. 회피·질주·강공격·패링 유지에 소비 | 시간 자동 회복(비행동 시 가속), 처형 성공 시 즉시 전량 | 탈진 상태 2초: 회피 불가, 피격 경직 1.5배 |
| **도력(道力)** | 道 | 술법 자원. 모든 도술·검 소환 응용기에 소비 | **검격 적중 시 회수(주 수단)**, 처형, 부적, 사당 | 도술 시전 불가. 소환 유지 중이던 검진(劍陣) 소멸 |

### 3.2 보조 게이지: 신기(神氣)
- 전투 중 "잘 싸울수록" 차는 게이지(패링 성공, 처형, 무피격 콤보, 환술 적중). 피격 시 일부 감소.
- 100% 도달 시 **신기해방(神氣解放)** 발동 가능: 12초간 백연의 신수 본연의 기운이 흘러나와 도력 소비 없음 + 검 소환 개수 상한 +2 + 이동속도 상승. 아홉 꼬리가 빛으로 전개되는 연출(기능 아님, P3 준수).
- 신기는 전투 종료 시 50%로 감쇠 → "아껴서 보스에 몰빵"을 절반만 허용.

### 3.3 자원 상호작용 룰 (룰북 발췌)
1. 도력이 20% 미만이면 꼬리의 여우불 연출이 꺼진다(시각적 자원 경고, HUD 의존 감소 — 03 문서 연계).
2. 기력과 도력은 서로 변환 불가. 단, 권능 '역천(逆天)' 각인 시 탈진 순간 도력 30을 태워 기력 50% 즉시 회복(1전투 1회).
3. 처형은 기력 전량 + 도력 30 회복 + 신기 15 상승의 "잭팟"으로, 마이크로 루프의 종착점 보상 역할을 한다.

## 4. 도술(道術) 시스템 설계

### 4.1 4계열 구분
백연의 도술은 4계열로 나뉜다. 각 계열은 명확한 전투 역할과 상호작용 태그를 가진다.

| 계열 | 한자 | 역할 | 대표 술법 | 상호작용 태그 |
|------|------|------|-----------|---------------|
| **검령술(劍靈術)** | 劍 | 사인참사검 소환 운용 — 공격의 축 | 허공발도, 검침(劍針), 다중소환, 검진 | `소환체`, `강타` |
| **호화술(狐火術)** | 火 | 여우불 — 화속 원거리·지속딜·부여 | 호화탄, 불여우 갈기(검 인챈트), 도깨비불 유도탄, 화막 | `화기`, `점화` |
| **환영술(幻影術)** | 幻 | 환술·매혹 — 기만과 군중 제어 | 환영 분신, 매혹(蠱惑), 둔갑 연막, 몽환진 | `환혹`, `어그로` |
| **신행술(神行術)** | 行 | 이동·공간 — 위치 선점과 회피 확장 | 축지 스텝, 검침 도약(검 위치로 순간이동), 여우 변화, 안개 걸음 | `전이`, `가속` |

### 4.2 계열 간 상호작용 (조합 룰)
도술은 단독보다 **조합**에서 가치가 폭발하도록 설계한다. 대표 조합 12선 중 발췌:

| 조합 | 입력 순서 | 결과 |
|------|-----------|------|
| 검침 × 축지 | 검침(적/지형에 검 꽂기) → 신행 | 꽂힌 검의 위치로 순간이동 + 도착 시 발도 베기 자동 발동 |
| 호화 × 검령 | 호화탄을 소환 대기 중인 검에 통과시킴 | 검이 `점화` 인챈트 → 명중 시 화상 도트 + 사기 노출 게이지 가속 |
| 환영 × 검령 | 분신 생성 → 다중소환 | 분신도 환영검을 소환(딜 없음, 적 회피·가드 유도) → 진짜 검의 명중률 상승 |
| 매혹 × 처형 | 매혹된 적은 `사기 노출` 즉시 부여 | 매혹 → 처형 직행 루트. 단 매혹 저항 적군 존재(02 문서) |
| 화막 × 몽환진 | 화막 위에 몽환진 중첩 | '겁화몽(劫火夢)': 범위 내 적 공포 도주 + 화상 (도력 대량 소비, 쿨 김) |

- **조합 판정 룰**: 두 술법의 태그가 유효 조합표에 있으면 후행 술법이 강화판으로 변조된다. 조합표는 인게임 '도술서(道術書)' 메뉴에서 발견한 것만 열람 가능 → 실험 유도.

### 4.3 시전 방식
- 도술은 **인장(印章) 휠**(홀드로 시간 감속 + 4방향 선택)과 **퀵슬롯 4개**(즉시 시전) 이중 구조. 액션 흐름을 끊지 않는 것이 최우선(입력 상세: 02·03 문서).
- 모든 도술은 시전 모션 중 검술 입력으로 **캔슬 가능 여부**가 태그로 정의된다(02 문서 §3).

## 5. 성장 시스템 — "신격 복원(神格復元)" (꼬리 해금 대체 설계)

### 5.1 설계 의도
- 봉인은 백연의 신격을 **아홉 신위(神位)가 아닌, 세 가지 '권능의 축'** 으로 흩어 놓았다. 성장은 이 축을 되찾는 과정이다. 숫자 9와 꼬리를 성장 구조에서 완전히 배제한다.
- "레벨업으로 강해진다"가 아니라 "본래의 나를 되찾는다"는 감각: 신규 능력의 상당수가 튜토리얼 회상(봉인 전 백연 조작 시퀀스)에서 먼저 체험된다.

### 5.2 3축 권능 각인(權能刻印) 트리
| 축 | 이름 | 테마 | 대표 각인 예시 |
|----|------|------|----------------|
| 1축 | **심판(審判)** | 검령술·처형·공격 | '사검쌍인'(동시 소환 상한 +1), '뇌정발도'(허공발도에 감전 추가), '참사연격'(처형 후 5초 공속 +20%) |
| 2축 | **기망(欺罔)** | 환영술·매혹·신기 | '이중환영'(분신 2체), '고혹심화'(매혹 지속 +3초), '허실전환'(분신과 위치 교대 시 무적 0.4초) |
| 3축 | **수호(守護)** | 생존·기력·신행 | '금강호신'(패링 판정 +4프레임), '축지연장'(축지 거리 +30%), '역천'(§3.3) |

- **각인 재화**: 전투·탐험으로 얻는 **정기(精氣)** + 축별 키 아이템 **신물(神物)** (보스·비경 보상). 정기만으로는 소각인, 신물이 있어야 대각인 해금.
- **각인 재배치**: 사당에서 무료 리스펙 허용(정기 반환 100%). 빌드 실험 장려 — 단 신물 해금 여부는 유지.

### 5.3 봉인구(封印具) 해제 — 스토리 게이트 성장
- 백연의 몸에는 4개의 봉인구(팔찌·귀걸이·비녀·족쇄)가 남아 있다. 각 장 보스 격파 시 하나씩 풀리며 **시스템 차원의 확장**이 일어난다:
  1. 팔찌 해제 → 검침 도약 해금 (신행-검령 조합의 문 개방)
  2. 귀걸이 해제 → 인장 휠 4칸 → 8칸 확장
  3. 비녀 해제 → 여우 변화(완전 여우 형태) 전투 중 사용 가능
  4. 족쇄 해제 → 신기해방 2단 '현신(現身)' 해금
- 봉인구는 "잃었던 것의 반환"이므로 P3(신격의 격) 준수. 수집형 해금이 아니라 서사 이정표.

### 5.4 부적(符籍) 장비 시스템 — 수평 성장
- 사당에서 부적 3장 착용(후반 4장). 부적은 조건부 효과(예: "도력 50% 이상일 때 검격 +10%", "화상 중인 적 처형 시 도력 추가 회수").
- 부적은 드랍·제작·기연(히든 이벤트)으로 획득. 등급 없음, **역할만 다름** — 파밍 트레드밀 방지(04 문서 §5 연계).

### 5.5 성장 총량 요약
- 수직 성장: 권능 각인(3축 각 12노드) + 봉인구 4단 + 체력/기력/도력 그릇 확장(비경의 '영천수' 수집).
- 수평 성장: 부적 조합, 도술 조합표 발견, 검술 파생기 습득(검총(劍塚)의 사범 영혼에게 전수).
- 목표 곡선: 1회차 클리어 시점에 전체 성장의 약 75% 도달, 나머지는 회차/탐험 완주 보상(04 문서 §2).

## 6. 변신(變化) 시스템 — 구미호다움의 축

| 형태 | 용도 | 제약 |
|------|------|------|
| **인간형 백연** | 기본 전투·대화 | — |
| **여우 형태(변화)** | 탐험 특화: 이동속도 1.6배, 영맥 감지, 좁은 굴 통과, 은신 접근 | 초반에는 비전투 지역 한정. 봉인구 3단 해제 후 전투 중 변신 → 여우 급습(뒤잡기 처형 시동기) 가능 |
| **현신(現身)** | 신기해방 2단. 12초간 거대 신수 실루엣이 겹쳐지는 최종 해방 상태 | 종장 직전 해금. 보스전 연출·기믹과 결속 |

- 변신은 게이지 소모가 아니라 **상황 전환 도구**로 설계 — "언제 여우가 되는가"가 플레이어의 공간 독해 능력을 표현한다.

## 8. 리스크와 열린 과제
1. 도술 조합표의 발견 난이도 — 너무 숨기면 시스템이 죽는다. 플레이테스트에서 1장 내 최소 3조합 자연 발견률 80% 목표.
2. 검격→도력 회수 루프가 "근접 강요"로 느껴질 수 있음 — 호화술 적중 시 소량 회수(50% 효율) 예외 검토 중.
3. 신기해방의 파워 스파이크가 보스 밸런스를 깨지 않도록, 보스는 해방 중 1회 '기세 되받기'(해방 시간 -4초) 패턴 보유(02 문서 §7).
