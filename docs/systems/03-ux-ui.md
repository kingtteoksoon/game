## 1. UX 원칙

| # | 원칙 | 적용 |
|---|------|------|
| U1 | **화면은 그림, 정보는 몸에** | 자원 상태를 캐릭터 연출로 이중 표현(꼬리 여우불=도력, 검의 빛=사기 노출). HUD는 보조 |
| U2 | **3초 룰** | 전투 중 필요한 모든 판단 정보는 시선 이동 3초 이내 획득. 전투 중 텍스트 팝업 금지 |
| U3 | **멈추지 않는 흐름** | 도술 선택(인장 휠)은 일시정지가 아닌 시간 감속(0.15배). 완전 정지는 메뉴뿐 |
| U4 | **발견의 존중** | 도술 조합·기연 등은 시스템이 먼저 답을 알려주지 않음. 힌트는 세계(벽화·문헌) 안에 배치 |
| U5 | **모두의 참사검** | 접근성 옵션은 별도 모드가 아니라 표준 설정의 일부. 첫 부팅 시 접근성 프리셋 선택 제공 |
| U6 | **검은 어디에 있는가** (신설, 판정 §1.2) | 사인참사검의 현재 소재(손/허공/꽂힘/비행)는 어떤 화면 상태에서도 1초 내 판독 가능해야 한다. 검의 소재가 곧 전투의 축이므로, 이 정보의 가독성은 체력보다 우선순위가 높다 |

## 2. HUD 레이아웃

### 2.1 배치도 (1920×1080 기준)
```
┌─────────────────────────────────────────────────────────┐
│ [A] 좌상: 자원 다발                     [B] 우상: 목표/나침 │
│  체력(홍) ━━━━━━━━━                      은은한 달 나침반    │
│  기력(청) ━━━━━                                            │
│  여우구슬(금) ●●●●●   신기(백) ◐                           │
│                                                           │
│                    (전투 공간 — 중앙 클린)                  │
│           [C] 적 머리 위: 체력 미니바+사기 게이지            │
│                                                           │
│ [D] 좌하: 인장 휠 축약(퀵슬롯 4)        [E] 우하: 영약/부적  │
│                                        [F] 하단 중앙:      │
│                                            검의 소재 표시   │
└─────────────────────────────────────────────────────────┘
```
- HUD 예시의 여우구슬은 **초기 상태 5개**(●●●●●)로 표기한다. 그릇 확장 시
  최대 8개(●●●●●●●●)까지 늘어난다. ※ 구판의 '구슬 7개' 예시는 C-17 판정으로
  수정되었다 — 9개 표기는 '9=꼬리' 오독을 낳으므로 어떤 아트/목업에서도 금지.

### 2.2 요소별 상세
| 요소 | 형태 | 규칙 |
|------|------|------|
| 체력 | 붉은 비단 띠. 감소 시 띠가 타들어가는 연출 | 30% 이하: 띠 가장자리 흔들림 + 심장 저음(시각+청각 이중화) |
| 기력 | 청색 얇은 띠, 체력 하단 | 탈진 시 띠가 회색 균열로 2초 고정 표시 |
| **여우구슬**(도력, C-17) | 금색 여우구슬 5개(영천수 확장 시 최대 8). 검격 적중 시 구슬로 기운이 빨려드는 파티클 | 구슬 방식 채택 이유: "도술 몇 번 가능"을 셈 없이 직관 파악. 신검 분리 상태(01 문서 §2.0)에는 구슬 둘레에 회복 가속 서기(瑞氣) 연출 |
| 신기 | 백색 달 문양, 차오르는 월상(초승달→보름달) | 만월 시 은은한 맥동 + 꼬리 연출 강화(U1). 꼬리는 빛날 뿐 개수 불변(판정 §4-12) |
| 사기 게이지(적) | 적 체력바 아래 자주색 실. 만충 시 적 몸의 인장 발광 + **참사(斬邪) 프롬프트**(간결한 검 아이콘) | 참사 가능 상태는 HUD 없이도 적 발광만으로 판별 가능해야 함. 인간형 적은 인장 대신 **흰 매듭 발광 + 제압 프롬프트**로 구분(비살상 분기, C-13) |
| **검의 소재 표시** (U6, 판정 §1.2) | 하단 중앙, 사인검 도안 1개가 4상태로 변화: ①손 = 도안 채움 ②허공 = 도안 윤곽선+옛 봉인 문양 ③꽂힘 = 도안이 지면에 꽂힌 실루엣+거리 표기 ④비행 = 잔상 흐름 애니메이션 | 검이 화면 밖에 꽂혀 있으면 화면 가장자리 방향 마커. 검침 도약 홀드 시 마커 확대 + 시간 감속. **검은 항상 한 자루이므로 표시도 항상 1개**(D-2) — 다중 마커·카운터 UI 금지 |
| 진(陣) 지속 표시 | 전개 중인 진의 문양 소형 아이콘 + 남은 지속 링 (검의 소재 표시 좌측) | 진은 검침 상태에서만 존재하므로 ③ 상태와 항상 동반 표시(`07` §1) |
| 동적 은폐 | 비전투 8초 경과 시 HUD 전체 페이드아웃(80%→0%), 전투/피격/입력 시 즉시 복귀 | 옵션에서 상시 표시/상시 최소 선택 가능. 단 검의 소재 표시는 '상시 최소'에서도 유지(U6) |

### 2.3 다이어제틱 표현 대응표 (U1 실현)
- 도력 20% 미만 → 꼬리 여우불 소등 (01 문서 §3.4)
- 사기 노출 → 적 몸 인장 발광 / 인간형은 흰 매듭 발광(제압)
- 검의 소재 → 백연의 오른손 소매 인장이 ①~④ 상태별로 다르게 발광(HUD를 끄고도
  플레이 가능한 이중화 — U6)
- 위공 → 적신 살기 이펙트 + 북소리 1타 (02 문서 연계)
- 저체력 → 화면 가장자리 한지(韓紙) 물든 핏빛 번짐 (비네트 강도 옵션화)

## 3. 메뉴 구조

### 3.1 메뉴 트리 (C-02·C-12 반영)
```
[일시정지 / 장승·서낭당 / 개시 공통 루트]
├── 도술서(道術書) ─ 습득 도술, 발견한 조합표, 시전 데모 영상
├── 신편(神篇) ─ 8갈래 회복 현황(필수 4=봉인구 매개 / 선택 4), 갈래별 심화 노드,
│                그릇(영천수) 확장 현황, 기억 회상 재열람 입구
├── 행낭(行囊) ─ 부적 장착(3~4슬롯)·진 부적 재고, 영약, 신물, 기타 수집물
├── 검총(劍塚) ─ 검술 파생기 목록, 수련장(허수아비 방) 입장
├── 기록(記錄) ─ 요마도감, 지도, 문서고 열람본(원본 열람·수집은 개시 문서고 — `07` §5)
├── 설정 ─ 화면 / 소리 / 조작 / 접근성 / 언어
├── (장승·서낭당 전용) 휴식(자원 충전+적 리팝), 개시로 축지 이동
└── (개시 전용) 곱단 제작(부적·검 연마), 상거래, 문서고, 심화 리스펙, 의뢰판
```
- 기능 배치 원칙(C-12): **세이브·휴식 = 장승·서낭당 / 성장 개화 = 신편 성소(필드) /
  제작·문서고·리스펙·상점 = 개시.** 축지 패스트트래블은 장승 ↔ 개시.
- 깊이 규칙: 어떤 기능도 루트에서 **3뎁스 이내**. 가장 빈번한 '부적 교체'는
  2뎁스 + 원버튼 프리셋 3종.
- 일시정지 메뉴에서도 도술서·행낭 열람 가능(전투 중 제외 — 전투 중엔 설정만).

### 3.2 요마도감 UX
- 처치·제압한 적의 아키타입·위공 패턴·약점이 **민화(民畵) 화풍 삽화**와 함께 기록.
  3회 이상 사망한 적은 "대응 조언" 항목 자동 해금(공략 강요가 아닌 구제).
- 인간형 적은 '제압' 기록 시 도감에 이름과 사연이 남는다 — 수호자 관점(헌장
  필러 2)의 도감 보상. 회유한 요괴는 별도 '연(緣) 목록'에 기록(`07` §3).

### 3.3 신편(성장) 화면
- 8갈래를 **여덟 폭 병풍**으로 표현 — 갈래 회복 시 병풍 한 폭의 그림이 채색되고,
  심화 노드는 그림 속 별자리에 금니(金泥)를 입히는 연출.
- 필수 갈래 4폭에는 대응 봉인구(팔찌·귀걸이·비녀·족쇄)가 그림 하단에 묘사 —
  풀릴 때마다 봉인구가 바스러지는 애니메이션(C-02: 봉인구 = 갈래의 물리적 매개).
- 꼬리·9 숫자 모티프는 이 화면에서 사용 금지(헌장 §4 — 성장 UI와 꼬리의 시각적
  연결 자체를 차단).

## 4. 조작 스킴 (D-1·D-2 용어 반영)

### 4.1 게임패드 (기본)
| 입력 | 기능 |
|------|------|
| LS / RS | 이동 / 카메라 (RS 클릭: 락온 토글) |
| X / Y | 약공(유) / 강공(단) — Y홀드: 단(斷) 최대 차지 |
| B | 회피(유보), 이동 중 홀드: 질주 |
| A | 상호작용 / (사기 노출 대상 근접 시) 참사·제압 |
| LB | 패링(되받기) |
| RB + 방향버튼(D-Pad) | 도술 퀵슬롯 4 시전 |
| RB 홀드 | 인장 휠 전개(시간 감속) → RS로 선택 |
| RT | 검령 수식 버튼 (RT+X **허공섬** / RT+Y **검침** / RT홀드 **유전** / RT장홀드 **진(陣) 전개** — 검침 상태 + 진 부적 보유 시) |
| LT | 신행 (탭: 축지 스텝 / 홀드: 검침 도약 — 검이 꽂힘 상태일 때) |
| 검이 손에 없을 때 X/Y | **응검(應劍)** 자동 선행 후 공격 연결 / 락온 없이 Y단독 홀드: **환검(還劍)** |
| D-Pad 상 | 영약 사용 |
| LS 클릭 | 여우 변화 (비전투: 즉시 / 전투: 필수 신편 3 「현형」 이후) |
| L3+R3 동시 | 신기해방 |
- 전 버튼 리매핑 지원. 홀드/토글 전환 옵션(RT·RB·질주 각각 개별).
- 구 '검우(RT홀드)·검진(RT장홀드)' 바인딩은 D-2 판정으로 폐기 — 동일 슬롯을
  유전·진이 승계하므로 근육 기억 설계는 유지된다.

### 4.2 키보드/마우스
| 입력 | 기능 |
|------|------|
| WASD / 마우스 | 이동 / 카메라 |
| 좌클릭 / 우클릭 | 약공 / 강공(홀드: 단 최대 차지) |
| Space | 회피, W+Space 질주 |
| Q | 패링 |
| E | 상호작용 / 참사·제압 |
| 1~4 | 도술 퀵슬롯 |
| Tab 홀드 | 인장 휠(마우스 선택) |
| Shift + 좌/우클릭 | **허공섬** / **검침** (Shift홀드: **유전**, 장홀드: **진 전개**) |
| Ctrl | 신행 (탭 축지 / 홀드 검침 도약) |
| G | 환검(검을 허공으로 되돌림 — 신검 분리 상태 진입) |
| F | 여우 변화, R 영약, V 신기해방 |
- 마우스 조준 이점(허공섬 정밀 조준)이 있으므로, 패드에는 소환 조준 보정각
  ±12° 제공(옵션 0~20°).

### 4.3 입력 버퍼·반응성 규격
- 입력 버퍼: 12f (선입력 큐 1개). 캔슬 창 진입 시 버퍼 자동 소비.
- 버튼-화면 반응 목표: 총 지연 ≤ 100ms (엔진 파이프라인 요건, 05 문서 §4).
- 응검(허공→손)은 0f 대기 원칙 — "검이 늦게 온다"는 감각은 조작감 치명상이므로
  이펙트는 손 위에서 맺는다(05 문서 §3.2 검의 소재 상태 관리 연동).

## 5. 접근성 옵션

| 분류 | 옵션 |
|------|------|
| 시각 | UI 스케일 80~130% / 색약 3모드(적·녹·청) — 위공·백공 살기를 색+**문양**(가시 vs 물결)으로 이중 구분 / **오방색 기호(지역 결계·리드라인) 판별을 색약 3모드 전부에서 QA 검증 항목으로 고정(R3 판정)** / 화면 흔들림·히트스톱 강도 0~100% / 비네트·혈흔 개별 오프 / 고대비 적 외곽선 토글 / 검의 소재 표시 확대 모드(하단 중앙 → 좌상 자원 다발 옆 복제) |
| 청각 | 자막 크기 3단 + 화자 색상 / 효과음 시각화(위공 북소리 → 화면 방향 표식) / 모노 오디오 / 대사·효과·음악 개별 볼륨 |
| 조작 | 전 키 리매핑 / 홀드→토글 전환 / 연타 요구 제거(참사·잡기 풀기 자동화) / 저스트 입력 판정 창 확장(홀린 걸음 4f→8f, 패링 6f→10f — 도전과제 무관 유지) / 한손 조작 프리셋(패드·키마 각 1종) |
| 난이도 보조 | 서사 모드(피해 -40%, 보스 P1 패턴 수 축소 — 04 문서 §2.1) / 조준 보정 강도 / 전투 슬로우(상시 0.85배) 토글 / 모든 보조는 언제든 개별 on/off, 세이브 낙인 없음 |
| 인지 | 목표 리마인더(나침반 강조) / 요마도감 대응 조언(§3.2) / 튜토리얼 재열람 상시 가능 / 검의 소재 음성 콜아웃 옵션("검, 허공" 등 짧은 내레이션) |

## 6. UI 아트 디렉션 — 한국 전통 미학

"**달빛 아래 한지에 그린 민화**" — 화려한 단청보다 먹과 여백, 그 위에 금박 한 점.

### 6.3 화면별 적용 예
- **타이틀**: 먹빛 산수 위 봉인 부적이 찢어지며 로고 현판 「백연(白緣): 마지막
  신수」 낙하(C-19 확정 타이틀).
- **신편 화면**: 여덟 폭 병풍 + 별자리 금니 연출(§3.3).
- **로딩**: 스피너 금지 → 백연의 붓이 여우 한 마리를 그려가는 일러스트(민화
  호작도 스타일). 로딩 팁은 세계관 문헌(문서고) 인용문 — 개시가 근처로 옮겨
  온다는 설정이 패스트트래블 로딩의 서사적 알리바이(컨셉 03 문서 §1.1).
- **참사 연출 프레임**: 화면 상하에 순간적으로 먹 여백 레터박스 + 낙관(落款)
  도장 이펙트 — 남용 방지 위해 보스 참사에만. 연출 문법은 '베어 죽임'이 아니라
  **사기만 발라내는 정화**로 통일(C-13): 적신 먹이 걷히고 본래 색이 돌아오는
  컬러 그레이딩 1컷을 표준 포함.

## 7. 온보딩 흐름 (C-05·C-06·C-18 반영)
1. **오프닝 = 각성**(C-05 판정: 봉인 전 회상 프롤로그 기각). 월음굴에서 눈을
   뜨는 순간부터 플레이 시작. 파워 판타지 선체험은 삭제하는 것이 아니라 **신편
   기억 컷신(플레이어블 회상)으로 분산 배치** — 갈래를 회복할 때마다 '완전했던
   백연'을 짧게 조작한다(신편 화면에서 재열람 가능, §3.1).
2. 응검·환검은 **게임 시작부터 기본 문법**(C-06). 첫 5분 안에 "검은 뽑는 것이
   아니라 부르는 것"임을 월음굴 어둠 속 응검 연출로 각인시킨다.
3. 튜토리얼 텍스트는 화면 정지 팝업 대신 **동행자 무영의 대사 + 입력 아이콘
   1줄**로 처리. (구 '먹비' NPC는 C-18 판정으로 삭제 — 온보딩 화자는 무영으로
   통일. 무영 합류 전 월음굴 구간은 벽화·삭은 부적 등 환경 힌트로 대체)
4. 첫 4시간 내 학습 순서: 검술 스트링 → 회피/패링 → 응검·환검(소재 전환) →
   허공섬(잿골 나루, 필수 신편 1 — 시퀀스 2) → 검침/도약(동일 갈래) → 인장 휠 →
   조합(첫 조합은 레벨 디자인으로 강제 발견).
