# 백연(白淵): 마지막 신수 (가제)

> "봉인에서 깨어난 마지막 신수 구미호"

천 년 전 인간과 요괴를 모두 수호하던 신수(神獸) 구미호 **백연**이
봉인에서 깨어나, 사인참사검(四寅斬邪劍)을 허공에서 소환하며
검술과 도술로 싸우는 3인칭 액션 어드벤처.
