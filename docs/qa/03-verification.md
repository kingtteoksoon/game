## 3. 신설 문서 4종 정합성 검증

### 3.1 systems/06(보스전 7전) ↔ concept/03(레벨 플로우)

- **정합**: 7전 라인업·지역 배정·전장 설정이 레벨 정본과 1:1 일치(거루귀 부두→선상 2단, 산군 2페이즈·오방색 아레나·"정화" 마무리·무음 하산 연결, 범도 굿당 1:1·총성 리듬, 헛것 용 조수 기믹 인용, 황천 감속·의례전, 서란→허주 2단). §0.2 소재 시험 매트릭스는 "보스마다 다른 소재를 시험"하는 우수한 추가 설계이며, 06 §9의 자체 정합 체크리스트도 본 검수와 전 항목 일치함을 확인.
- **불일치**: ① 거루귀(첫 보스) 대응 패턴이 **유전(流轉)** 사용을 전제하나 유전의 해금 시점이 어느 문서에도 없다(N-12) ② §3.4 패턴명 "발도목"(N-06) ③ §7.2 P3 "신격의 뿌리 **아홉 갈래** 게이지"(N-13, 총괄 확인 권고).

### 3.2 systems/07(사이드 시스템) ↔ systems/01(코어 자원)

- **정합**: 진(陣)=Planted 전제·도력 대 밴드(40~60, 04 문서와 일치)·동시 1개(검 한 자루로 자동 성립), 변신 해금=필수 신편 3·4 귀속, 매혹·회유·제압의 자원 비용이 04 §3.3과 일치, 부적=장비+진 부적=소모품 분리(03 행낭 UI와 일치), 문서고=개시 귀속, §8 시스템 간 연결 총괄표까지 상호참조 무결.

## 6. 결론 — 프리프로덕션 착수 판정

**판정: 조건부 착수 가능(Go with conditions).**

- 1차 검수에서 착수를 막던 구조적 문제(두 개의 게임, 헌장 위반, 코어 메커니즘 시점 충돌)는 판정과 v2 개정으로 전부 해소됐다. 기획 세트는 서사–레벨–시스템–기술–고증이 단일한 게임을 가리키고 있으며, M0(그레이박스 소환 프로토타입)은 **지금 정의된 사양만으로 착수 가능**하다 — N 항목 중 M0 범위(응검·환검·허공섬·검침·도약·유전 프로토타입)를 막는 것은 없다.
- 단, 아래 우선순위를 조건으로 부기한다.

**우선순위 목록 (미비점 처리 순서)**
1. **[총괄 재판정, 즉시] N-02 '세 번의 경인' 정정** — 판정문 추록 갱신 1건 + 문구 수정 5개소. 방치 시 고증 포지셔닝(R11)의 역풍 소재. 권장안: "두 번의 경인, 천 년의 봉인".
2. **[총괄 판정, M0 첫 스프린트 내] N-01 봉인구↔갈래 매핑 확정** — 컨셉·시스템 각 2~3개소 수정. 신편 화면(03 §3.3)·레벨 배치(03 §3.2)가 이 매핑을 참조하므로 늦출수록 비쌈.
3. **[파트 합의, M0 내] N-03 신검 분리 정의·수치 단일화 + N-04 여우구슬 정체 분리** — M0 프로토타입이 분리 보상 수치를 직접 검증하므로(05 §2.0), 착수 전 02 문서 기준으로 시트 1장 통일 필수.
4. **[총괄 확인, M1 전] N-05 침식 재방문 범위(R2) 재확정, N-13 아홉 갈래 게이지 승인 여부.**
5. **[기계적 수정, 수시] N-06~N-12** — 표기·잔존 참조 7건. 금지어 grep을 문서 머지 체크리스트에 상설화하면 재발 방지.

## 7. 최종 요약

- **판정 이행률: 29건 중 완전 이행 25건(86%) / 부분 이행 4건(C-02, C-17, D-1, A-1) / 미이행 0건 — 실효 이행률 약 93%.** 리스크 방침 12건 중 11건 이행, 1건 부분(R2).
- **신규 발견: 13건** (중 4: N-01 봉인구 매핑 상충 / N-02 '세 번의 경인' 간지 오류 / N-03 신검 분리 수치 3원화 / N-04 여우구슬 정체 이중화, 하 9: N-05~N-13).
- 1차 검수의 22건은 전건 처리 확인. 기획 세트는 **조건부 프리프로덕션 착수 가능** 상태이며, 조건은 §6의 우선순위 1~3(총괄 재판정 1건 + 매핑 판정 1건 + 수치 단일화)이다.
