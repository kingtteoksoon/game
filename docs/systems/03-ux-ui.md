# 03. UX/UI 기획서 — 《백연(白緣): 사인참사검》

- 문서 버전: v0.3 (2026-07-02)
- 담당: UX/UI 디자이너
- 선행 문서: `01-core-mechanics.md`, `02-combat-design.md`
- 대상 플랫폼: PC(패드/키마), 콘솔 확장 고려. 기준 해상도 1920×1080, UI 스케일 80~130%.

## 1. UX 원칙

| # | 원칙 | 적용 |
|---|------|------|
| U1 | **화면은 그림, 정보는 몸에** | 자원 상태를 캐릭터 연출로 이중 표현(꼬리 여우불=도력, 검의 빛=사기 노출). HUD는 보조 |
| U2 | **3초 룰** | 전투 중 필요한 모든 판단 정보는 시선 이동 3초 이내 획득 가능해야 함. 전투 중 텍스트 팝업 금지 |
| U3 | **멈추지 않는 흐름** | 도술 선택(인장 휠)은 일시정지가 아닌 시간 감속(0.15배)으로 처리. 완전 정지는 메뉴뿐 |
| U4 | **발견의 존중** | 도술 조합·기연 등은 시스템이 먼저 답을 알려주지 않음. 힌트는 세계(벽화·문헌) 안에 배치 |
| U5 | **모두의 참사검** | 접근성 옵션은 별도 모드가 아니라 표준 설정의 일부. 첫 부팅 시 접근성 프리셋 선택 제공 |

## 2. HUD 레이아웃

### 2.1 배치도 (1920×1080 기준)
```
┌─────────────────────────────────────────────────────────┐
│ [A] 좌상: 자원 다발                     [B] 우상: 목표/나침 │
│  체력(홍) ━━━━━━━━━                      은은한 달 나침반    │
│  기력(청) ━━━━━                                            │
│  도력(금) ●●●●●○○  신기(백) ◐                              │
│                                                           │
│                    (전투 공간 — 중앙 클린)                  │
│           [C] 적 머리 위: 체력 미니바+사기 게이지            │
│                                                           │
│ [D] 좌하: 인장 휠 축약(퀵슬롯 4)        [E] 우하: 영약/부적  │
│                                        [F] 하단 중앙:      │
│                                            검침 마커 카운터 │
└─────────────────────────────────────────────────────────┘
```

### 2.2 요소별 상세
| 요소 | 형태 | 규칙 |
|------|------|------|
| 체력 | 붉은 비단 띠. 감소 시 띠가 타들어가는 연출 | 30% 이하: 띠 가장자리 흔들림 + 심장 저음(시각+청각 이중화) |
| 기력 | 청색 얇은 띠, 체력 하단 | 탈진 시 띠가 회색 균열로 2초 고정 표시 |
| 도력 | 금색 여우불 구슬 7개(그릇 확장 시 증가). 검격 적중 시 구슬로 기운이 빨려드는 파티클 | 구슬 방식 채택 이유: "도술 몇 번 가능"을 셈 없이 직관 파악 |
| 신기 | 백색 달 문양, 차오르는 월상(초승달→보름달) | 만월 시 은은한 맥동 + 꼬리 연출 강화(U1) |
| 사기 게이지(적) | 적 체력바 아래 자주색 실. 만충 시 적 몸의 인장 발광 + 처형 프롬프트(간결한 검 아이콘) | 처형 가능 상태는 HUD 없이도 적 발광만으로 판별 가능해야 함 |
| 검침 마커 | 하단 중앙 최대 4개 검 아이콘. 꽂힌 검은 실루엣 점등, 화면 밖 검은 화면 가장자리 방향 마커 | 도약 홀드 시 마커가 확대되고 시간 감속(02 문서 §4.2) |
| 동적 은폐 | 비전투 8초 경과 시 HUD 전체 페이드아웃(80%→0%), 전투/피격/입력 시 즉시 복귀 | 옵션에서 상시 표시/상시 최소 선택 가능 |

### 2.3 다이어제틱 표현 대응표 (U1 실현)
- 도력 20% 미만 → 꼬리 여우불 소등 (01 문서 §3.3)
- 사기 노출 → 적 몸 인장 발광
- 위공 → 적신 살기 이펙트 + 북소리 1타 (02 문서 §5.2)
- 저체력 → 화면 가장자리 한지(韓紙) 물든 핏빛 번짐 (비네트 강도 옵션화)

## 3. 메뉴 구조

### 3.1 메뉴 트리
```
[사당 화면 / 일시정지 공통 루트]
├── 도술서(道術書) ─ 습득 도술, 발견한 조합표, 시전 데모 영상
├── 신격(神格) ─ 권능 각인 3축 트리, 봉인구 상태, 그릇 확장 현황
├── 행낭(行囊) ─ 부적 장착(3~4슬롯), 영약, 신물, 기타 수집물
├── 검총(劍塚) ─ 검술 파생기 목록, 수련장(허수아비 방) 입장
├── 기록(記錄) ─ 백연의 기억(회상 재열람), 요마도감, 지도
├── 설정 ─ 화면 / 소리 / 조작 / 접근성 / 언어
└── (사당 전용) 축지 이동, 휴식(자원 충전+적 리팝), 제작
```
- 깊이 규칙: 어떤 기능도 루트에서 **3뎁스 이내**. 가장 빈번한 '부적 교체'는 2뎁스 + 원버튼 프리셋 3종.
- 일시정지 메뉴에서도 도술서·행낭 열람 가능(전투 중 제외 — 전투 중엔 설정만).

### 3.2 요마도감 UX
- 처치한 적의 아키타입·위공 패턴·약점이 **민화(民畵) 화풍 삽화**와 함께 기록. 3회 이상 사망한 적은 "대응 조언" 항목 자동 해금(공략 강요가 아닌 구제).

## 4. 조작 스킴

### 4.1 게임패드 (기본)
| 입력 | 기능 |
|------|------|
| LS / RS | 이동 / 카메라 (RS 클릭: 락온 토글) |
| X / Y | 약공(유) / 강공(단) — Y홀드: 발도 |
| B | 회피(유보), 이동 중 홀드: 질주 |
| A | 상호작용 / (사기 노출 대상 근접 시) 처형 |
| LB | 패링(되받기) |
| RB + 방향버튼(D-Pad) | 도술 퀵슬롯 4 시전 |
| RB 홀드 | 인장 휠 전개(시간 감속) → RS로 선택 |
| RT | 검령 수식 버튼 (RT+X 허공발도 / RT+Y 검침 / RT홀드 검우 / RT장홀드 검진) |
| LT | 신행 (탭: 축지 스텝 / 홀드: 검침 도약 마커 선택) |
| D-Pad 상 | 영약 사용 |
| LS 클릭 | 여우 변화 (비전투: 즉시 / 전투: 봉인구 3단 이후) |
| L3+R3 동시 | 신기해방 |
- 전 버튼 리매핑 지원. 홀드/토글 전환 옵션(RT·RB·질주 각각 개별).

### 4.2 키보드/마우스
| 입력 | 기능 |
|------|------|
| WASD / 마우스 | 이동 / 카메라 |
| 좌클릭 / 우클릭 | 약공 / 강공(홀드 발도) |
| Space | 회피, W+Space 질주 |
| Q | 패링 |
| E | 상호작용/처형 |
| 1~4 | 도술 퀵슬롯 |
| Tab 홀드 | 인장 휠(마우스 선택) |
| Shift + 좌/우클릭 | 허공발도 / 검침 (Shift홀드: 검우, 장홀드: 검진) |
| Ctrl | 신행 (탭 축지 / 홀드 도약) |
| F | 여우 변화, R 영약, V 신기해방 |
- 마우스 조준 이점(허공발도 정밀 조준)이 있으므로, 패드에는 소환 조준 보정각 ±12° 제공(옵션 0~20°).

### 4.3 입력 버퍼·반응성 규격
- 입력 버퍼: 12f (선입력 큐 1개). 캔슬 창 진입 시 버퍼 자동 소비.
- 버튼-화면 반응 목표: 총 지연 ≤ 100ms (엔진 파이프라인 요건, 05 문서 §4).

## 5. 접근성 옵션

| 분류 | 옵션 |
|------|------|
| 시각 | UI 스케일 80~130% / 색약 3모드(적·녹·청) — 위공·백공 살기를 색+**문양**(가시 문양 vs 물결 문양)으로 이중 구분 / 화면 흔들림·히트스톱 강도 0~100% / 비네트·혈흔 효과 개별 오프 / 고대비 적 외곽선 토글 |
| 청각 | 자막 크기 3단 + 화자 색상 / 효과음 시각화(위공 북소리 → 화면 방향 표식) / 모노 오디오 / 대사·효과·음악 개별 볼륨 |
| 조작 | 전 키 리매핑 / 홀드→토글 전환 / 연타 요구 제거(처형·잡기 풀기 자동화) / 저스트 입력 판정 창 확장(홀린 걸음 4f→8f, 패링 6f→10f — 도전과제 무관 유지) / 한손 조작 프리셋(패드·키마 각 1종) |
| 난이도 보조 | 서사 모드(피해 -40%, 보스 P1 패턴 수 축소 — 02 문서 §7.6) / 조준 보정 강도 / 전투 슬로우(상시 0.85배) 토글 / 모든 보조는 언제든 개별 on/off, 세이브 낙인 없음 |
| 인지 | 목표 리마인더(나침반 강조) / 요마도감 대응 조언(§3.2) / 튜토리얼 재열람 상시 가능 |
- **원칙**: 접근성 옵션 사용이 콘텐츠·엔딩·도전과제를 잠그지 않는다(서사 모드 포함).

## 6. UI 아트 디렉션 — 한국 전통 미학

### 6.1 무드 키워드
"**달빛 아래 한지에 그린 민화**" — 화려한 단청보다 먹과 여백, 그 위에 금박 한 점.

### 6.2 디자인 토큰
| 토큰 | 값/방향 |
|------|---------|
| 바탕 질감 | 한지(닥종이) 텍스처. 메뉴 배경은 먹 번짐(발묵) 애니메이션 |
| 1차 팔레트 | 먹색 #1C1A17, 한지백 #F2EAD3, 단사홍(체력) #C1442E, 쪽빛(기력) #2C5F72, 금니(도력) #C9A227 |
| 2차 팔레트(강조) | 자수정(사기) #6E4B8E, 달백(신기) #E8E3D5 |
| 프레임/장식 | 조각보 직선 분할 + 매듭(다회) 모티프. 단청 문양은 사당·성장 화면 등 '신성 공간'에만 절제 사용 |
| 아이콘 | 부적 도안(경면주사 붉은 획) 스타일. 도술 4계열은 사신도가 아닌 **사인검 명문(銘文) 서체** 변형으로 통일 |
| 타이포 | 한글 제목: 붓글씨 궁체 기반 커스텀 / 본문: 고딕 계열 가독 우선(전통은 제목·장식에만) / 한자 병기는 툴팁에서만 |
| 모션 | 메뉴 전환 = 두루마리 펼침/족자 낙하. 이징은 붓의 삐침처럼 빠른 진입-잔결 마무리(0.25s 내) |
| 사운드 UI | 커서: 가야금 하모닉스 단음 / 확정: 장구 궁편 / 오류: 태평소 짧은 꺾임음(불쾌하지 않게 -6dB) |

### 6.3 화면별 적용 예
- **타이틀**: 먹빛 산수 위 봉인 부적이 찢어지며 로고 현판 낙하.
- **신격(성장) 화면**: 3축 트리를 별자리(천상열차분야지도 모티프)로 표현 — 각인은 별에 금니를 입히는 연출.
- **로딩**: 로딩 스피너 금지 → 백연의 붓이 여우 한 마리를 그려가는 일러스트(민화 호작도 스타일). 로딩 팁은 세계관 문헌 인용문.
- **처형 연출 프레임**: 화면 상하에 순간적으로 먹 여백 레터박스 + 낙관(落款) 도장 이펙트 — 남용 방지 위해 보스 처형에만.

## 7. 온보딩 흐름
1. 프롤로그 = 봉인 전 회상(완전체 백연 조작): 모든 시스템을 파워 판타지 상태로 15분 체험 → 봉인 → 상실감과 함께 본편 시작(01 문서 §5.1 연계).
2. 튜토리얼 텍스트는 화면 정지 팝업 대신 **동행 NPC '먹비(먹으로 된 까마귀)'의 대사 + 입력 아이콘 1줄**로 처리.
3. 첫 4시간 내 학습 순서: 검술 스트링 → 회피/패링 → 허공발도 → 검침/도약 → 인장 휠 → 조합(첫 조합은 레벨 디자인으로 강제 발견).
