# 02. 전투 디자인 기획서 — 《백연(白緣): 사인참사검》

- 문서 버전: v0.3 (2026-07-02)
- 담당: 전투 디자이너
- 선행 문서: `01-core-mechanics.md` (자원·도술 계열·성장 정의)
- 프레임 기준: 60fps 고정 표기 (1f = 16.67ms)

---

## 1. 전투 아이덴티티

- **한 문장**: "검이 손이 아니라 공간에 있다" — 소환 위치를 설계하는 검술.
- 템포 목표: 다크소울보다 빠르고 데빌 메이 크라이보다 무겁게. 참고 좌표: 《세키로》의 읽기-응수 + 《니어:오토마타》의 유동성 중간점.
- 평균 교전 시간 목표: 잡몹 1체 8~12초, 정예 25~40초, 보스 페이즈당 90~150초.

## 2. 검술 콤보 체계

### 2.1 기본 입력 사전
| 입력 | 명칭 | 기능 |
|------|------|------|
| 약공(X/좌클릭) | 유(流) | 빠른 베기, 도력 회수 주력 (회수량 소, 횟수 다) |
| 강공(Y/우클릭) | 단(斷) | 느린 참격, 가드 크러시·자세 게이지 딜 |
| 홀드 강공 | 발도(拔刀) | 차지 발도. 차지 중 소환 예약 입력 가능(§4) |
| 회피(B/Space) | 유보(柳步) | 스텝 회피, 기력 22 소비 |
| 패링(LB/Q) | 되받기 | 상대 공격에 맞춰 검면으로 흘리기 |
| 도술(RB+방향/E) | 인장 | 퀵슬롯 도술 시전 |
| 소환 조작(RT/Shift) | 검령 | 소환 계열 전용 수식 버튼(§4) |

### 2.2 콤보 스트링 (기본 6종 + 파생)
표기: 유=약공, 단=강공. 모든 스트링의 마지막 타는 '마무리 속성'을 가진다.

| 스트링 | 입력 | 총 프레임 | 마무리 속성 | 용도 |
|--------|------|-----------|-------------|------|
| 유수사연(流水四連) | 유-유-유-유 | 92f | 넉백 소 | 기본 도력 회수 |
| 낙월(落月) | 유-유-단 | 78f | 다운 유발 | 잡몹 눕히기 |
| 파산(破山) | 단-단 | 84f | 자세 대미지 2배 | 슈퍼아머 적 |
| 회란(回蘭) | 유-단-유-유 | 96f | 360도 범위 | 포위 대응 |
| 천붕(天崩) | 단-유-단 | 102f | 공중 띄우기 | 공중 콤보 시동 |
| 참사일섬(斬邪一閃) | 홀드 발도 최대 차지 | 48f(발동) | 사기 노출 게이지 +40% | 처형 셋업 |

- **파생 룰**: 스트링 3타 이후 회피 입력 시 '유보 베기'(회피+공격 겸용, 기력 30)로 파생. 스트링 임의 시점에 검령 버튼 → 소환기 캔슬(§3).
- **공중 전투**: 천붕 이후 공중 유 3연 + 공중 검침(적을 지면에 내리꽂음). 공중은 짧은 양념으로, 체공 위주 게임이 아님.

### 2.3 사기 노출(邪氣露出)과 처형
- 모든 요마는 체력 바 아래 **사기 게이지**를 가진다. 강공·패링·특정 도술로 누적, 가만두면 서서히 감소.
- 게이지 만충 → 8초간 `사기 노출` 상태(몸의 인장이 빛남) → 근접 처형 입력 시 **참사(斬邪) 처형**: 즉사(잡몹)/대미지 25%+경직(정예·보스).
- 처형 보상: 기력 전량, 도력 +30, 신기 +15 (01 문서 §3.3). 전투 리듬의 마침표.

## 3. 도술-검술 캔슬/연계 규칙

### 3.1 캔슬 우선순위 표 (위가 아래를 캔슬 가능)
```
1. 패링 (거의 모든 자세를 캔슬 — 최후의 안전망, 단 실패 시 후딜 큼)
2. 회피(유보) — 검술 스트링의 '캔슬 창'에서만
3. 신행술 (축지 스텝 / 검침 도약)
4. 소환기 (허공발도 / 다중소환 예약)
5. 검술 스트링 다음 타
6. 기타 도술 시전 모션
```

### 3.2 캔슬 창(Cancel Window) 룰
- 모든 검격은 `타격 판정 종료 후 ~ 후딜 60%` 구간이 캔슬 창. 데이터 태그 `cancel: [dodge, mystic, summon]`로 기별 정의(05 문서 연계).
- **도술 → 검술 캔슬**: 투사체형 도술(호화탄 등)은 발사 직후 검술로 캔슬 가능. 설치형(검진, 몽환진)은 시전 완료까지 캔슬 불가 — 리스크 차등화.
- **연계 보너스 "허실(虛實)"**: 환영술 적중 후 2초 내 검격은 크리티컬 확정 + 도력 회수 1.5배. "속인 뒤 벤다"(P2)를 수치로 보증.
- 동일 도술 연속 시전 시 도력 비용 +25% 누진(3회에서 리셋) — 원버튼 스팸 억제.

## 4. 사인참사검 소환 메커니즘 상세

### 4.1 기본 개념
- 백연은 검을 "휴대"하지 않는다. 검은 평소 접혀 있는 공간에 있으며, 공격 입력 순간 손에 현현하고 스트링 종료 후 흩어진다(발도-납도가 소환-소멸).
- **소환 슬롯**: 동시에 실체화 가능한 검의 수. 기본 1자루 → 각인 '사검쌍인'으로 2 → 최대 4 (신기해방 중 +2).

### 4.2 소환 기술 4종 — 입력 → 판정 → 쿨다운
| 기술 | 입력 | 발동/판정 | 비용 | 쿨다운 |
|------|------|-----------|------|--------|
| **허공발도(虛空拔刀)** | 검령 + 약공 (조준 방향) | 조준점 8m 내 적 측면 공간에 검이 소환되어 횡베기. 발동 18f, 판정 6f. 소환 위치는 적 기준 '플레이어 반대편' — 협공 감각 | 도력 15 | 없음 (도력이 제약) |
| **검침(劍針)** | 검령 + 강공 | 검을 투척해 적/지형에 꽂음(비관통 대미지 소). 꽂힌 검은 20초 유지, 월드에 마커 표시. 최대 소환 슬롯 수만큼 동시 유지 | 도력 10 | 없음 |
| **검침 도약(劍針跳躍)** | 검침 유지 중 신행 버튼 홀드 → 마커 선택 | 꽂힌 검 위치로 순간이동(0.5초 무적) + 도착 즉시 발도 베기(추가 입력 시). 적에게 꽂힌 검으로 도약 시 그 적에게 '허실' 부여 | 도력 20 | 3초 (연속 도약 난사 방지) |
| **다중소환 — 검우(劍雨)** | 검령 홀드 1초 → 해제 | 슬롯 수만큼의 검이 상공에 배열 후 조준 지점에 순차 낙하(검당 발동 간격 8f). 낙하 지점 데칼 표시(적도 회피 시도) | 도력 12×자루 | 6초 |

### 4.3 검진(劍陣) — 설치형 궁극 운용
- 검침 3자루 이상이 반경 10m 내에 꽂혀 있을 때 검령 버튼 장홀드 → **검진 전개**: 검들 사이에 결계 라인 생성, 라인을 지나는 적에게 속박 1.5초 + 지속 대미지. 유지 중 도력 초당 4 소모.
- 검진 내부에서 백연의 검격은 도력 회수 2배 — "판을 깔고 싸우는" 플레이 스타일의 정점.

### 4.4 소환 판정 공통 룰
1. 소환 위치가 벽/장애물과 겹치면 가장 가까운 유효 지점으로 보정, 보정 거리 1.5m 초과 시 시전 실패(도력 50% 환불).
2. 소환된 검은 독립 오브젝트가 아니라 **본체의 연장** — 적 AI는 검을 개별 타겟팅하지 않는다(어그로 시스템 단순화, 05 문서 연계). 예외: 일부 보스는 검침을 뽑아 던지는 카운터 보유(§7).
3. 허공발도·검우의 대미지는 백연의 공격력 스탯을 그대로 참조(별도 소환수 스탯 없음, 04 문서 §3).

## 5. 회피와 패링

### 5.1 회피 — 유보(柳步)
- 무적 프레임: 발동 후 2f~10f (총 9f i-frame). 각인 '축지연장'으로 거리, '금강호신' 계열로는 확장 불가(무적 인플레 방지).
- 저스트 회피 "**홀린 걸음**": 피격 판정 4f 전 이내 회피 성공 시 → 시간 감속 0.8초 + 잔상(환영 판정: 적이 잔상을 공격) + 도력 10 회수. 구미호식 저스트 회피 정체성.
- 연속 회피 3회째부터 기력 비용 1.5배.

### 5.2 패링 — 되받기
- 판정 창: 입력 후 6f (각인으로 최대 10f). 성공 시 적 자세 게이지 +대, 신기 +8.
- **위공(危攻) 시스템**: 적의 특수 공격은 몸에서 붉은 살기가 피어오름(청각: 북소리 1타 동반). 위공은 패링 불가·회피만 가능 ↔ 백색 살기는 패링 시 '되받아 베기' 자동 반격. 색약 대응은 문양 차이 병행(03 문서 §5).
- 패링 실패(헛침) 후딜 24f — 남발 억제. 단 매혹 상태의 적 공격은 패링 판정 창 2배(기만 시너지).

## 6. 적 아키타입 (7종) 와 대응 전략

| # | 아키타입 | 예시 개체 | 행동 특성 | 의도된 카운터 | 잘못된 접근 시 |
|---|----------|-----------|-----------|----------------|-----------------|
| 1 | **군체(群體)** | 아귀 떼, 잡귀 | 3~8체 무리, 개별 약함, 포위 이동 | 회란(범위 스트링), 검우, 화막 | 단일 대상 스트링 고집 → 등 뒤 피격 |
| 2 | **쾌속 습격형** | 창귀(倀鬼) | 은신 접근, 짧은 선딜 연속 베기, 백스텝 이탈 | 홀린 걸음 → 허실 카운터, 검침 도약으로 이탈 추격 | 정면 콤보 → 이탈당해 딜 로스 |
| 3 | **중장 파쇄형** | 강시(殭屍), 두억시니 | 슈퍼아머, 위공 위주, 느리지만 치명적 | 파산으로 자세 붕괴, 매혹으로 무리에서 격리 | 약공 연타 → 아머 무시 반격에 역관광 |
| 4 | **술법 지원형** | 타락 무격(巫覡) | 후방에서 아군 강화·부활, 결계 생성 | 검침 도약으로 후방 급습(우선 제거 학습), 매혹 시 아군 오폭 | 앞줄부터 처리 → 무한 부활 소모전 |
| 5 | **영역 장악형** | 물귀신, 그슨대 | 지형(물·어둠)에 잠복, 끌어당기기·잡기 | 호화술로 영역 정화(물 증발/어둠 밝힘) 후 교전, 잡기는 회피 전용 | 영역 내 근접전 → 잡기 콤보로 대미지 폭사 |
| 6 | **기만 반사형** | 어둑시니, 요호(妖狐) | 플레이어의 환술 모방, 분신 생성, 매혹 저항 | 환술 봉인하고 순수 검술 승부 or 검진으로 진짜 색출(환영은 결계 라인에 반응 없음) | 매혹 시도 → 반사되어 백연이 3초 조작 반전 |
| 7 | **파괴 가능 거체(巨體)** | 장승 수호물, 불가살이 | 부위 파괴(팔·각·코어), 광역 내리찍기 | 검침을 약점 부위에 꽂아 마커 유지 → 도약 반복으로 부위 집중 파괴 | 지상 히트런만 반복 → DPS 부족 시간 초과(광폭화) |

- **배치 문법**: 조우 설계는 "주 아키타입 1 + 보조 1" 조합을 기본으로 하며, 4·5·6형은 단독 등장으로 먼저 학습시킨 후 조합 투입한다.
- 매혹 면역 규칙: 6형 전체, 보스, 무생물(1·7형 일부)은 매혹 면역 — 매혹 만능화 방지. 면역 대상에게 매혹 시전 시 도력 환불 없음(판단 실수 비용).

## 7. 보스전 설계 원칙

1. **소환 검증의 장**: 모든 보스는 소환 메커니즘 중 최소 1개를 "정답 열쇠"로 요구한다. 예: 1장 보스 '이무기'는 수중 잠행 중 검침을 등에 꽂아야 도약 추격 가능.
2. **3페이즈 문법**: P1 = 기본 패턴 학습 / P2 = 위공 추가 + 영역 변화 / P3 = 서사적 전환(배경·음악 전조) + 신기해방 유도 설계. 페이즈 전환은 체력 70%/35% 고정.
3. **기세 되받기**: 보스는 플레이어 신기해방 중 1회 한정 카운터(해방 -4초)를 가진다(01 문서 §8). 해방 타이밍도 읽기의 대상.
4. **검침 카운터**: 3장 이후 보스는 몸에 꽂힌 검침을 8초 내 뽑아 되던진다(투사체, 패링 가능) — 검침 방치 플레이 견제.
5. **처형 연출 통합**: 보스 격파는 반드시 사기 노출 → 참사 처형 입력으로 마무리(시네마틱 처형). "마지막 일격은 항상 플레이어의 손으로".
6. **재도전 존중**: 보스 룸 직전 사당 배치, 페이즈 스킵 없음 대신 P1 패턴 수 축소 옵션(접근성, 03 문서 §5). 컷신 재생 스킵 항상 가능.
7. **인연 서사 규칙**: 보스는 전부 백연의 과거 인연(01 문서 §2.3). 전투 중 대사가 패턴 전조를 겸한다(예: "그때처럼 숨어볼 테냐!" → 광역 색적기 예고) — 서사가 곧 텔레그래프.

### 7.1 장별 보스 라인업 (초안)
| 장 | 보스 | 아키타입 뿌리 | 소환 열쇠 | 서사 인연 |
|----|------|---------------|-----------|-----------|
| 1장 | 이무기 '흑택' | 영역(수중) | 검침 → 도약 추격 | 백연과 함께 승천을 기다리던 벗 |
| 2장 | 창귀 대장 '범아귀' | 쾌속 습격 | 허공발도로 이탈 경로 차단 | 백연이 지키지 못한 산군(호랑이)의 원귀 |
| 3장 | 타락 국무(國巫) '희단' | 술법 지원 | 검진으로 결계 부수기 | 봉인 의식의 집전자 |
| 3.5장 | 어둑시니 군주 | 기만 반사 | 검진 라인으로 진짜 색출 | 백연의 그림자에서 태어난 존재 |
| 4장 | 불가살이 '식철' | 파괴 가능 거체 | 부위 검침 마킹 → 반복 도약 | 봉인구를 삼킨 쇠 먹는 괴수 |
| 5장 | 요호 '매영' | 기만+습격 복합 | 매혹 반사 역이용(거울 대결) | 백연을 흉내 내는 아홉 번째 여우 |
| 6장/종장 | (서사 스포일러 — 별도 문서) | 전 기믹 종합 | 현신 결속 기믹 | 봉인의 진짜 이유 |

## 8. 상태이상 사전 (플레이어 ↔ 적 공용 규칙)
| 상태 | 부여 수단 | 효과 | 해제 |
|------|-----------|------|------|
| 화상(점화) | 호화술, 점화 인챈트 | 4초간 초당 도트 + 사기 게이지 누적 가속 | 시간 경과, 수중 |
| 감전 | 각인 '뇌정발도' | 0.8초 경직 + 다음 피격 자세 대미지 1.5배 | 시간 경과 |
| 매혹 | 환영술 | 적대 대상 반전 6초 (면역 규칙 §6) | 시간 경과, 피격 시 50% 확률 조기 해제 |
| 공포 | 겁화몽 | 도주 AI 3초, 방어 행동 불가 | 시간 경과 |
| 속박 | 검진 라인 | 이동 불가 1.5초 (거체는 0.5초) | 시간 경과 |
| (피아 공용) 탈진 | 기력 소진 | 회피 불가·경직 1.5배 2초 | 시간 경과 |
- 중첩 룰: 동일 상태 재부여는 지속시간 갱신(중첩 강화 없음). 화상+감전 등 이종 상태는 공존 허용, 매혹+공포는 후행 우선.

## 9. 전투 카메라·타격감 가이드 (요약)
- 락온: 소프트 락온 기본(입력 방향 보정), 하드 락온 토글. 군체전에서는 락온 해제 권장 UX(03 문서).
- 히트스톱: 유 2f / 단 5f / 처형 12f. 소환 발도류는 히트스톱 대신 카메라 펀치인 5% — 검이 여러 곳에서 터질 때 화면 정지 누적 방지.
- 피격 리액션 4단: 경직 소/대, 다운, 띄움. 거체(7형)는 부위 파괴 시에만 대형 리액션.
