# 백연(白緣): 마지막 신수 (가제)

> "봉인에서 깨어난 마지막 신수 구미호"

천 년 전 인간과 요괴를 모두 수호하던 신수(神獸) 구미호 **백연**(한국 토종 붉은여우)이
백두산 신전의 봉인에서 깨어나, 제 검 사인참사검(四寅斬邪劍)을 허공에서 되불러
검술과 도술로 싸우는 3인칭 액션 어드벤처.

- **주인공**: 백연(白緣, '맑은 인연'). 한국 토종 붉은여우 신수. 검·도술 하이브리드
- **무대**: 1890년 경인년의 조선 — 천 년의 봉인(890), 두 번의 경인(1470 쐐기·1890 각성)
- **전투의 축**: 단 한 자루뿐인 제 검의 **소재(所在)** — 손/허공/꽂힘/비행 중 어디에 둘 것인가
- **성장**: 과거의 힘을 줍는 게 아니라, 지금 지키고 맺는 **인연(因緣)**으로 힘을 되찾는다
- **무기**: 사인참사검은 태초부터 백연의 것인 원본 검. 조선 왕실 사인검들은 그 모작
