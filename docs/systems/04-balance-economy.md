## 1. 밸런스 철학

| # | 원칙 | 내용 |
|---|------|------|
| B1 | **숙련이 스탯을 이긴다** | 성장 총량은 플레이어 피해량 기준 1장 대비 종장 약 4배로 억제. 나머지 격차는 숙련(조합·처형·패링)에서 나오게 한다 |
| B2 | **자원 순환이 난이도다** | 어려운 구간 = 적 체력 인플레가 아니라 "도력 회수 기회가 위험해지는" 구간으로 설계 |
| B3 | **보상은 행동을 가르친다** | 탐험 보상 ≠ 전투 보상 ≠ 스토리 보상. 세 트랙을 재화 단위부터 분리해 어떤 플레이도 다른 트랙을 완전히 대체 못 하게 한다 |
| B4 | **파밍 트레드밀 금지** | 장비 등급/랜덤 옵션 없음. 부적은 역할 차등만(01 문서 §5.4). 반복 노가다가 최적해가 되지 않도록 재화 획득에 일일 감쇠 대신 '원천 고갈'(고정 배치) 채택 |

## 2. 난이도 곡선 설계

### 2.1 난이도 모드
| 모드 | 대상 | 조정 |
|------|------|------|
| 설화(說話) | 서사 중심 | 피해 -40%, 보스 P1 패턴 축소, 처형 게이지 누적 +30% |
| 전설(傳說) — 기본 | 액션 유저 표준 | 기준치 |
| 신화(神話) | 도전 유저 | 적 피해 +35%, 위공 빈도 +25%, 적 신규 파생 패턴 추가(체력 인플레 아님 — B2), 1회차부터 선택 가능 |
- 모드는 언제든 변경 가능(도전과제 무관). 사망 3연속 시 설화 권유 팝업은 **띄우지 않는다**(플레이어 자존 존중) — 대신 요마도감 조언 해금(03 문서 §3.2).

### 2.2 장(章)별 긴장 곡선 (전설 기준)
```
긴장도
 高 |                 ▲B5        ▲B6(종장)
    |        ▲B3   /  \   ▲B5.5/
 中 |  ▲B1  /  \  /    \  /
    | /  \ /    \/ 이완  \/
 低 |/    ▽휴식  ▽(비경·일상)
    +---------------------------------→ 진행
      1장   2장   3장   4장   5장   6장+종장
```
- 문법: 보스 직후 반드시 이완 구간(비경 탐험·일상 씬) 배치. 4장 중반에 의도적 난이도 스파이크(중간고사 보스 B3.5 '어둑시니 군주' — 환술 반사 학습 검증, 02 문서 아키타입 6형).
- 스파이크 상한: 직전 구간 평균 사망률의 2.5배 이내. 초과 시 레벨 디자인 수정 우선, 수치 너프는 차선.

### 2.3 구간 검증 지표
| 지표 | 1장 | 3장 | 6장 |
|------|-----|-----|-----|
| 잡몹 교전 평균 시간 | 10초 | 12초 | 14초 |
| 구간당 평균 사망 | 1~2 | 2~4 | 4~6 |
| 보스 평균 시도 | 3~5회 | 5~8회 | 8~12회 |
| 처형 발동률 | 50% | 60% | 65% |

## 3. 수치 프레임 (공식 초안)

### 3.1 플레이어 기본 스탯 (전설 기준, 1장 시작)
| 스탯 | 초기값 | 최대(종장) | 성장 수단 |
|------|--------|-----------|-----------|
| 체력 | 100 | 260 | 영천수(그릇 확장, 필드 12개 중 8개 상정) + 수호축 각인 |
| 기력 | 100 | 160 | 영천수 + 수호축 |
| 도력 | 구슬 5개(1구슬=20) | 구슬 9개 | 영천수 + 기망축 |
| 공격력(ATK) | 22 | 88 | 검 연마(사당 제작, 6단) + 심판축 각인 |
| 도술위력(MATK) | 20 | 76 | 신물 각인 + 기망축 |

### 3.2 대미지 공식
```
최종대미지 = 기본위력 × 모션계수 × (1 + Σ각인보정) × 허실계수 × 방어감쇠
  방어감쇠 = ATK² / (ATK + DEF×0.8)  ← ATK 우위 시 체감 손실 완만한 유리수형
  허실계수 = 1.5 (환술 적중 후 2초 내, 02 문서 §3.2), 평시 1.0
```
- 모션계수(발췌): 유 1.0 / 단 1.9 / 발도 최대차지 3.2 / 허공발도 1.4 / 검우 자루당 0.8 / 검침 0.5 / 처형(정예) 대상 최대체력의 25%.
- 크리티컬 없음(허실이 크리 역할) — 랜덤 대미지 분산 ±5%만 허용, 읽기 게임의 예측 가능성 유지.

### 3.3 자원 수치 (전투 경제)
| 항목 | 값 |
|------|-----|
| 유 1히트 도력 회수 | 4 (스트링 마무리 타 8) |
| 호화술 적중 회수 | 2 (근접 대비 50% 효율, 01 문서 §8.2 반영) |
| 회피 기력 | 22 (3연속째부터 33) |
| 패링 유지 기력 | 초당 10 (홀드 시) |
| 도술 비용 밴드 | 소(10~15): 호화탄·검침 / 중(20~30): 축지·매혹·검우 / 대(40~60): 몽환진·검진·겁화몽 |
| 신기 획득 | 패링 +8, 처형 +15, 환술 적중 +4, 무피격 10초 +5 / 피격 -10 |

### 3.4 적 스탯 스케일 공식
```
적 체력 = 기본HP × (1 + 0.35×(장-1)) × 아키타입계수
적 공격 = 기본ATK × (1 + 0.22×(장-1)) × 위공계수(위공 2.2)
아키타입계수: 군체 0.5 / 습격 0.8 / 중장 1.6 / 지원 0.7 / 영역 1.2 / 기만 1.0 / 거체 3.0(부위별 분할)
```
- 장당 성장률을 플레이어(복리 약 26%/장)보다 낮게(체력 35%/공격 22% 단리) 설정 → 회차 내 파워커브는 완만 우상향, 숙련이 주도(B1).
- 정예 접두어 시스템: '굶주린'(공+25%/체-15%), '완고한'(자세 게이지 +50%), '홀린'(사망 시 매혹 폭발) 등 7종 — 같은 적의 재사용 가치를 접두어로 확보.

## 4. 보상 구조 — 3트랙 분리 (B3)

### 4.1 트랙 정의
| 트랙 | 주 보상 | 보조 보상 | 설계 의도 |
|------|---------|-----------|-----------|
| **전투** | 정기(精氣) — 각인 재화 | 부적 재료(요마 소재), 신기 경험 | "잘 싸우면 강해진다" 수직 성장의 원천 |
| **탐험** | 영천수(그릇 확장), 부적 원본, 도술 조합 벽화, 월전(月錢) | 문헌(도감·설정) | "구석을 보면 넓어진다" 수평 성장 + 자원 상한 |
| **스토리** | 봉인구 해제(시스템 확장), 신물(대각인 열쇠), 검술 파생기 | 기억 회상(연출 보상) | "진행하면 문이 열린다" 게이트 성장 |
- 교차 금지 룰: 정기로 영천수를 살 수 없고, 월전으로 신물을 살 수 없다. 트랙 간 환전 부재가 세 행동 모두를 유의미하게 만든다.
- 전투 정기 보상은 **처치 방식 가중**: 처형 마무리 +30%, 무피격 클리어 +20%, 매혹 오폭 유도 +15%(중복 상한 +50%) — 보상이 전투 문법을 가르친다(B3).

### 4.2 사망 페널티
- 사망 시 미회수 정기 현장 잔류(1회 회수 기회, 소멸 없음 — 소울라이크식 영구 손실은 채택하지 않음: 정기 손실이 리스펙 실험(01 문서 §5.2)을 위축시키기 때문).
- 월전·신물·부적은 사망과 무관. 페널티의 본질은 "구간 재주행 시간"으로 한정.

### 4.3 기연(奇緣) 시스템 — 변동비율 보상
- 필드 곳곳의 저확률 특수 이벤트(둔갑한 노인, 은혜 갚는 까치 등). 보상은 유니크 부적·특수 회상.
- 기연은 **회차·지역당 고정 시드 배치**(순수 랜덤 아님) — 공략 공유 문화 허용하되 첫 발견의 놀라움 유지.

## 5. 재화 설계

### 5.1 재화 총람
| 재화 | 획득 | 사용처 | 싱크(소멸처) | 인플레 통제 |
|------|------|--------|--------------|-------------|
| **정기(精氣)** | 전투(§4.1) | 권능 각인, 검 연마 | 각인 비용 누진(노드당 1.4배) | 원천 고갈형: 리팝 적은 최초 처치의 40%만 지급 |
| **월전(月錢)** | 탐험 습득, 도깨비시장 되팔기 | 도깨비시장(영약 확장, 부적 재료, 지도 조각, 치장) | 소모품 구매 | 시장 재고 장(章)당 갱신, 무한 구매 불가 |
| **요마 소재** | 적 처치 드랍(아키타입별 고정 소재) | 부적 제작·강화 | 제작 소비 | 드랍률 고정 100%/개체, 수량으로만 차등(랜덤 감쇠 없음 — B4) |
| **신물(神物)** | 보스·비경 고정 보상 | 대각인 해금 | 1회성 키 아이템 | 총량 고정(비거래) |
| **영천수** | 탐험 고정 배치 12개 | 체/기/도 그릇 확장(택1) | 1회성 | 총량 고정 |
- 치장(무복 염색, 검 장식 매듭)은 월전 전용 + 성능 무관 — 탐험 동기의 장기 꼬리 담당.

### 5.2 도깨비시장 가격 프레임 (초안)
| 품목 | 가격(월전) | 비고 |
|------|-----------|------|
| 영약 소지 상한 +1 (최대 5회) | 300 → 450 → 675… (1.5배 누진) | 핵심 싱크 |
| 부적 재료 묶음 | 80~150 | 장별 재고 3 |
| 지도 조각(미답파 구역 실루엣) | 120 | 탐험 보조, 완전 공개 아님 |
| 치장류 | 200~800 | 성능 무관 |
- 장별 월전 공급 목표: 수요 총합의 80~90% (전부 사려면 되팔기·기연 필요 → 선택의 긴장).

### 5.3 이코노미 검증 시트 (추적 지표)
| 지표 | 목표 |
|------|------|
| 장별 정기 공급/각인 수요 비율 | 0.7~0.85 (전 노드 즉시 해금 불가) |
| 종장 시점 각인 완성도 | 평균 75% (01 문서 §5.5 일치) |
| 월전 잔고 중앙값 | 장 종료 시 200±100 (사재기·고갈 양극단 방지) |
| 리스펙 사용률 | 1회차 유저 40% 이상 (실험 문화 형성 확인) |

## 6. 성장 체감 이벤트 맵 (파워 스파이크 배치)
| 시점 | 이벤트 | 체감 |
|------|--------|------|
| 1장 말 | 봉인구 1(검침 도약) | 기동 혁명 — 전투 공간이 3차원화 |
| 2장 중 | 소환 슬롯 2 (사검쌍인) | 검우·검진의 실전화 |
| 3장 말 | 봉인구 2(인장 휠 8칸) | 빌드 다양성 개방 |
| 4장 중 | 스파이크 보스 B3.5 | 의도된 벽 — 조합 숙련 검증 |
| 5장 초 | 봉인구 3(전투 중 여우 변화) | 은신-급습 플레이 추가 |
| 6장 말 | 봉인구 4(현신) | 종장 파워 판타지 회수 |
- 규칙: 파워 스파이크 직후 구간은 신 능력의 '전용 놀이터' 조우를 최소 3개 배치해 체감을 보증한다.

## 7. 회차(뉴게임+) 설계 (요약)
- 계승: 각인·부적·치장 / 초기화: 봉인구(서사 게이트 재체험), 영천수.
- 회차 전용: 접두어 2중첩 정예, 유니크 부적 4종, 숨겨진 기연 1계통. 스탯 인플레 대신 패턴 추가로 난이도 부여(B2 일관).

## 8. 리스크 로그
1. 처형 가중 보상(+30%)이 처형 강박을 만들 수 있음 → 상한 +50% 및 시간 효율 관점 검증 필요.
2. 원천 고갈형 정기는 "망한 빌드로 재화 부족" 우려 → 무료 리스펙(100% 반환)으로 헤지, 추가로 회차당 총 공급이 수요의 120%가 되도록 여유분 배치.
3. 유리수형 방어감쇠는 저ATK 구간에서 체감 급락 가능 → 1장 적 DEF 상한 캡(플레이어 ATK의 60%) 설정.
